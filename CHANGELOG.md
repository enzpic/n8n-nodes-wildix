#### 1.1.0

Major expansion of the **Wildix** action node to full coverage of the WMS PBX REST API, audited against the official OpenAPI spec at the method+path level and validated against a live PBX.

**New operations (~60 across existing resources):**

- **Call** — legacy v1 channel ops (Get Call Status / Recordings / Tags, Set Call Tags, Make Call Legacy, Send DTMF / Transfer by Channel) and Originate Mobility Call
- **Call Queue** — Forward Call
- **Group** — Create / Update / Delete Call Group, Get Call Group Stats
- **Dialplan** — Create / Get / Update / Delete Dialplan, Dialplan Database key/value store (Get Family Keys, Get / Add / Update / Delete Value, Delete Family), Import Time Tables
- **Phonebook** — phonebook-scoped Contacts (Get Contacts, Get / Add / Update / Delete Contact, Delete All Contacts)
- **Trunk** — Trunk Price List Create / Update / Export / Delete
- **Colleague** — Get / Update User Presence (by extension), Get Many (Basic)
- **Sound** — Create / Update / Delete Directory
- **Application** — Update S2S Application
- **Alarm Clock** — Get, Delete
- **Voicemail** — Delete
- **Recording** — Download
- **PBX Settings** — Get SMTP Test Status · **PBX System** — Get Dictionaries · **PBX Upgrade** — Start Check · **Device** — Get iOS Config · **Personal** — Delete Location, Update Roster

**Fixes (HTTP method / path corrections verified against a live PBX):**

- **Device → Connect** now uses `POST /Devices/{mac}/connect/` (the previous `/devices/connect` route does not exist)
- **Personal → Get ACL** now sends the required `filter` parameter (previously returned HTTP 400)
- **Call → Set Active Device** corrected `POST` → `PUT`
- **Personal → Update Features** corrected `PUT` → `POST`
- **PBX System → Reboot** corrected `POST` → `PUT`

**Removed** (non-functional — no such GET endpoint exists on the PBX; these were PUT-only): Personal → Get Presence, Get Presence Location, Get Roster (use the corresponding Update operations).
